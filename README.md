# Hello World with Socket.IO in Node.js language

This is a basic Hello World project using Socket.IO and Node.js. The server sends a message to all connected clients using WebSockets, displaying the message in the browser.

## Clone repository

Use the following command:

```bash
git clone https://github.com/Karen020701/AppSocketIO-Js.git
```

## Install the project dependencies with npm:

```bash
npm install
```

## Run the program with the command:
```bash
npm start
```

The server will start at: http://localhost:3000 and you will see a message on the screen "Hello World with Socket.IO!"
